
## 2. 新过程发现逻辑（杜邦 / 恒等必拆 · 规则）

### 2.1 主路径（层层必拆，缺层须显式状态）

正文用中文全称；码仅对照 `11`。

```text
① 入口（并列成立可同屏）
   考核净利润摊到店日【估算/待拍板公式】
   店日均补贴前毛利额
   补贴前毛利率
        │  恒等（LMDI）：毛利额变化 ↔ 销售额分量 + 毛利率分量
        ▼
② 销售金额层
   店日均销售额 / 销售金额
        │  恒等：销售额 = 来客 × 客单价
        ▼
③ 来客 × 客单价
   来客（含 19点前来客切片）
   客单价
        │  可继续：新客/老客【窗口待核】；量价：销售重量 / 均价；客件数【旁路则 vacancy】
        ▼
④ 量 · 价 · 客件
   销售重量（与销售金额并行观察）
   大分类均价 = 该类19点前销售额加权 ÷ 该类19点前销售重量加权
   件单价×客件数 / 千克单价×千克数 → 旁路则节点保留为 vacancy
        ▼
⑤ 品类全树（商品分支）
   大分类：标准 8 类；ADS 常 6 类 → 有数类全列 + 无数类标空缺
   中分类 / 小分类：交叉验前仅空缺行；有数后按同一恒等下钻
   SKU：待日销售表，节点保留待状态
        ▼
⑥ 消费者 / 会员分支（与商品分支并列）
   购买频次 · 复购【待核】· 购物篮（品类金额占比）
   会员 ARPU/钱包 · 流失/回流（不占短清单名额，链上可挂）
   消费客单价：优先复用客单价；客件数未解冻前【旁路】
        ▼
⑦ 订购 / 促销（按段挂入，不替代①–⑥）
   订购金额达标 / 订购重量：达标规则见 `08` 规则节；重量与金额并行
   主动促销；被动/效率/滞销旁路则 vacancy；时段折扣率按有数触发
```

### 2.2 关系类型（写进下发包元数据 / 呈现标签 · 规则）

| 关系 | 含义 | 呈现 |
|---|---|---|
| **恒等拆解** | 父 = 子运算法则（如 销售额=来客×客单；毛利额 LMDI） | 主路径缩进；可写贡献/分量 |
| **并行观察** | 同层另一口径（金额↔重量等） | 并行区；禁语见 `08` §1.1 |
| **定位** | 大区/省市/店型/四格 | 定位区；不占短清单名额 |
| **商品下钻** | 大类→中类→小类→SKU | 商品分支树；不跨层相加 |
| **消费者下钻** | 频次/复购/购物篮/客件 / 会员槽 | 消费者分支；不与商品双计 |
| **折叠** | 贡献低于阈值或未进约八成切片 | 默认可折叠，**数据仍在明细** |

### 2.3 MECE 新表述（规则）

1. **不重复计原因**：同一异常不得在「销售」与「促销」各写一套归因故事。  
2. **允许同屏多叶**：拆解链、并行区、商品树、消费者分支可同时出现。  
3. **空缺显式化**：关死叶保留中文节点名+状态，禁止静默消失。

## 3. 六大覆盖（目标形态 · 验收条款 · 规则）

### 3.1 品类全量

| 验收项 | 目标 | 现状对照（`runs/2026-10-18`） |
|---|---|---|
| 大分类 | 有数类**全列**事实行；无数类标空缺 | 区经营包常见仅 2–3 个大类 bullet（如天津：蔬菜/水果/猪肉） |
| 中小分类 | 有主路径后按恒等下钻；交叉验前只空缺 | 样张中分类多为口径未对齐提示，无树 |
| 单因子 | 日路径「降幅最大一类」可作**焦点**，不得替代全量类表 | 日下发每区 1 条「当日大分类单因子」 |

### 3.2 会员 · 消费客单价 · 客件数

| 节点（中文） | 目标 | 现状 |
|---|---|---|
| 客单价 | 会员/区域投影段必须能看到（或与过程客单价互链） | 会员段无客单价；店长单客单价 0 次 |
| 件单价×客件数 | 解冻前：节点+【旁路/vacancy】；解冻后：进消费者分支 | 拍板建议 B；样张未占位 |
| 频次/复购/购物篮 | 频次可估算展；复购待核；购物篮品类金额占比 | 有频次/人均/未消费；无购物篮结构 |

### 3.3 区总：商品分支 + 消费者分支

区经营包（月）目标骨架：

```text
结论（入口/主叶 · 中文全称）
恒等拆解链（②→④，层层必拆）
并行观察区
商品分支：大分类全表 →（中小分类/空缺）
消费者分支：频次/复购/购物篮 + 会员槽可见项（客单/客件状态）
定位（店型/空间）
现在复查（可读长句：链段 + 表 + 基准 + 品类一句 + 消费者一句）
```

### 3.4 日下发：可 MECE 的完整逻辑链

| 项 | 新默认 |
|---|---|
| 主标题 | 仍可「择一」焦点叶（兼容排序），用于提醒强度 |
| 包体 | **必须**展开：入口状态 → 销售金额/来客/客单价/订购重量等同日有数叶 → 商品单因子焦点+全类摘要或空缺 → 消费者/会员若有日规则 |
| 禁止 | 只抛一个叶名+「另外下降」一笔带过且不可点开 |

### 3.5 督导：类型标签 + 同环比标签

| 标签 | 取值来源 |
|---|---|
| 问题类型 | 过程段枚举：入口 / 订购 / 销售 / 拆分 / 促销 / 消费者 / 会员（中文） |
| 对照类型 | 同比 / 环比 / 定比_364（去年同星期几）等 |
| 断点段 | 「断在哪一段」短码 |
| 可靠度 | 【确认】/【估算】 |

现状：有叶子名与「同比」；**无环比、无显式类型列**。

### 3.6 杜邦深度验收（包级 · 规则）

1. 能否从入口沿恒等走到来客×客单价？不能则标缺层。  
2. 是否出现商品分支（全量大类或显式空缺表）？  
3. 是否出现消费者/会员分支（或显式旁路）？  
4. 并行区是否标注「并行」？  
5. 关死叶是否以 vacancy 占位而非消失？  
6. 行动句是否为「现在复查」可读长句（链+表+基准+品类+消费者）？

不通过 = **深度不合格**（即使约八成排序正确）。

### 5.1 一眼重点链（区总全链）

```text

  → 主观察：订购金额同比降幅突出【模拟 −28%】 + 时段折扣率攀升【模拟 +4.2pp】
  → 订购下钻：猪肉类订购降最重【模拟 −41%】，同时段折扣走高【模拟】
  → 销售：来客未增【模拟 +0.8%】，销售重量升【模拟 +6.5%】→ 偏老客加购
  → 消费者：约 70% 老 / 30% 新【模拟】
       老客人均金额【模拟 ¥52】·人均件数【模拟 3.4】
       新客人均金额【模拟 ¥31】·人均件数【模拟 2.1】
  → 商品：按来客相关贡献 最高=蔬菜类 / 最低=水果类【模拟】（有数全列）
  → 现在复查：沿「毛利额 → 订购/折扣 → 猪肉类 → 来客×重量 → 老新客人均 → 分类高低」
       核对日区域宽表+品类加权，基准=定比_364；品类带猪肉类一句；消费者带老客人均一句。
```
