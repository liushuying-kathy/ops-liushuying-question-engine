## 1. §4 MECE 全树穷尽

摘自：`【本机真源：问题引擎/门店经营诊断问题引擎_落地方案.md】` **§4**（叶子名与方案一致，不另发明）。码↔中文见 `11`。

### 1.1 过程树 / 入口树（全文穷尽）

```text
入口（并列）
  考核净利润摊到店日 (E1)          → 工作算法；非月结/税前/某日净利
  店日均补贴前毛利额 (E2)
  补贴前毛利率 (E3)                → 店日均补贴前毛利额 ÷ 店日均销售额（加权后再除）

定位
  管理区域 / 运营大区 / 省 / 市
  店型 × 开业天数；分层（头/中上/中下/尾）
  品类 按 §3.1，不跨层相加

过程（呈现按 `10` 杜邦必拆同屏多叶；MECE=同一异常不双计）
  订购
    订购金额达标 (O1)
    订购重量 (O2)
  销售
    销售金额 / 店日均销售额 (S1)
    销售重量 (S2)
  销售拆分（金额 = 来客 × 客单价）
    来客 (B1)；新客/老客 (B1a/B1b)
    客单价 (B2)；客单价×新老客 (B2a)；客单价×大分类 (B2b)
  促销
    19点前促销折扣率 (M1)；主动 (M1a)；被动 (M1b)
    时段折扣率 (M2)；促销效率 (M3)；滞销/连续无销售 (M4)
  消费者（三叶分开，不合成一行）
    购买频次 (C1a)；复购 (C1b)；购物篮 (C1c)
    件单价×客件数 (C2a)；千克单价×千克数 (C2b)

会员槽（不占区域经营短清单）
  会员 ARPU/钱包 (T10)；流失/回流 (T15)

定位标签（写入区域单或店型行，不占短清单名额）
  尾部、新店、签开闭、直营、商品门、不良、费用
```

### 1.2 恒等与并行（§4.1 摘要，非新叶）

| 类型 | 内容（方案原文要点） |

| 恒等 | 店日均补贴前毛利额变化 ↔ 销售额分量 + 毛利率分量（LMDI）；销售额 = 来客 × 客单价；全天销售额 = 19点前 + 19点后；会员来客 = 留存 + 新增 + 回流；等 |
| 并行观察 | 销售金额 ↔ 销售重量；订购金额 ↔ 订购重量；主动促销额 ↔ 19点前折扣率（关系标签与禁语见 `08`/`10` 规则节） |

| 日扫 | 不跑促销段 (M1–M4) |

## 2. 标杆示例形态【目标深度模拟】（一眼重点 · 分角色投影）
