## 导读

门店=最小经营主体；问题自下而上聚合；各层**同一观察链**，差异只在聚合粒度与折叠。

```text
共用链（天津区模拟）：店日均补贴前毛利额弱于大盘
  → 订购金额降 + 时段折扣率升
  → 猪肉类订购降最重且该品类折扣升
  → 来客持平、销售重量升（偏老客加购）
  → 老/新客占比与人均金额·件数
  → 商品来客最高/最低
  → 现在复查（核对已呈现表与数；不叫人另算）
```

## 1. 店长（本店）

> 粒度=单店（最小经营主体）；全链在本店成立叶上展开。

**本店店日均补贴前毛利额同比 −15%【模拟】。**  
订购金额同比 −20%【模拟】，时段折扣率升至 ×1.5【模拟】；其中**猪肉**订购金额 −30%【模拟】、该品类折扣 ×1.9【模拟】。来客持平【模拟】、销售重量 +8%【模拟】（偏老客加购）。今日老客 72% / 新客 28%【模拟】；老客人均 ¥40·3.0 件【模拟】，新客 ¥26·1.7 件【模拟】。本店来客最高商品：叶菜 A【模拟】；最低：冰鲜 B【模拟】。

**现在复查：**核对店长单「订购 / 促销 / 销售与客流 / 消费者」段——猪肉订购与折扣是否同向；老客人均件数是否仍约 3.0；冰鲜 B 是有货无人还是断货（对照本店商品高低表，基准=同比）。

## 2. 督导（名下店聚合）

> 粒度=名下店；链同构，投影为「断在哪一段」+ 跟店优先。

**名下 12 店中 5 店店日均补贴前毛利额弱于大盘【模拟】；共性：订购降 + 时段折扣升，猪肉最重。【模拟】**  
跟店优先：店×01 / ×03 / ×07（来客持平、销售重量升【模拟】）。类型=订购·促销；对照=同比。

同链缩影（这 3 家共性【模拟】）：订购金额降 + 时段折扣升 → 猪肉订购降幅重于名下均、该品类折扣偏高 → 来客平、重量升 → 老客人均金额·件数高于新客 → 商品来客高=叶菜类、低=冰鲜类（店间可有差，以店长单为准）。

**现在复查：**打开督导任务单对照这 3 家店长单——猪肉订购与折扣是否同向；是否同一配送/定价动作；类型标签是否仍为订购·促销、对照=同比。

## 3. 区总（天津区 · 全链）

> 粒度=管理区聚合；链与店长单同构，店明细折叠进区。

**天津区 · 店日均补贴前毛利额同比 −12%【模拟】，弱于全国大盘 −5pp【模拟】。**  
订购金额 −18%【模拟】 + 时段折扣率 ×1.4【模拟】；订购缺口里猪肉订购 −27%【模拟】且该品类折扣 ×1.8【模拟】。来客持平【模拟】、销售重量 +6%【模拟】。今日老/新 70%/30%【模拟】；老客人均 ¥42·3.1 件【模拟】，新客 ¥28·1.8 件【模拟】。商品来客最高叶菜 A、最低冰鲜 B【模拟】。

**现在复查：**沿「店日均补贴前毛利额 → 订购金额/时段折扣率 → 猪肉类 → 来客×重量 → 老新客人均 → 大分类高低」核对日区域宽表与品类加权表；基准优先同比（定比_364 作并行对照）；品类侧带着猪肉订购与折扣是否同向；消费者侧带着老客人均金额·件数是否仍高于新客；商品侧带着冰鲜 B 空缺/有货状态。

## 4. 运营经理（加厚 · 战区）

> 粒度=战区；链不变，只改聚合与邻区对照、其他区折叠。**信息密度须接近区总**（同链写满，禁止三句话打发）。

**战区一眼：**天津区店日均补贴前毛利额同比 −12%【模拟】，拖累本战区店日均补贴前毛利额约 −4pp【模拟】（战区合计弱于大盘约 −3pp【模拟】）。邻区对照【模拟】：邻区甲订购金额约 −8%、猪肉折扣约 ×1.2；邻区乙订购约 −11%、猪肉折扣约 ×1.3——天津区订购 −18%、猪肉折扣 ×1.8，订购降幅与猪肉折扣均明显重于邻区。

**同链写满（只改聚合，不删段）：**
1. **入口**：天津区毛利额同比 −12%，弱于全国大盘 −5pp【模拟】；对战区拖累如上。  
2. **订购 + 时段折扣**：订购 −18% + 时段折扣 ×1.4【模拟】（邻区对照见上）。  
3. **猪肉**：订购缺口内猪肉 −27%、该品类折扣 ×1.8【模拟】。  
4. **来客 × 重量**：来客持平、销售重量 +6%【模拟】→ 偏老客加购，非来客扩张。  
5. **新老客人均**：老/新 70%/30%；老客人均 ¥42·3.1 件，新客 ¥28·1.8 件【模拟】。  
6. **商品高低**：来客最高叶菜 A、最低冰鲜 B【模拟】。  
7. **战区折叠其他区**：战区内其余管理区未进本条焦点的，折叠为一句「贡献未进本战区约八成切片，明细仍在战区宽表」【模拟】——不删数据，只折叠呈现。

**现在复查：**核对战区经营包天津区节——毛利额拖累幅度是否仍约 −4pp；邻区订购/猪肉折扣差是否仍显著；同链各段数字与区总包一致；折叠区是否仍不必展开店清单。

## 5. CEO（加厚 · 公司）

> 粒度=全国贡献折叠；链不变，只留进约八成的区节要点并展开三点。**信息密度须接近区总**。

**全国贡献序：**天津区店日均补贴前毛利额弱于大盘【模拟】，全国毛利额缺口贡献排序约第 3 位【模拟】（累加进约八成权重的下发包节）。

**同链三点展开（各带数字【模拟】）：**
1. **订购**：天津区订购金额同比 −18%【模拟】，与时段折扣 ×1.4【模拟】同向出现——全国表上该区订购缺口进头部。  
2. **猪肉 × 折扣**：订购缺口内猪肉 −27%、该品类折扣 ×1.8【模拟】——品类焦点仍是猪肉类订购+折扣，非全品类均摊。  
3. **老客撑重量、非来客**：来客持平、销售重量 +6%【模拟】；老/新 70%/30%，老客人均 ¥42·3.1 件 vs 新客 ¥28·1.8 件【模拟】——重量升由老客加购结构支撑，不是来客扩张。

**其余区折叠：**全国约八成切片外其余管理区默认可折叠，一句说明「未进本周约八成贡献切片，明细仍在全国宽表/区经营包」【模拟】；不在 CEO 屏铺店清单与督导名册。

**商品/消费者各留一句（与区总同链，不删）：**商品来客最高叶菜 A、最低冰鲜 B【模拟】；消费者结构见上老新客人均。

**现在复查：**核对本周重点战区清单是否仍含天津区（或天津区所属战区）；打开全国毛利额贡献序表与品类加权摘要——天津区位次是否仍约第 3、订购/猪肉折扣/老客加购三点是否仍成立；不要求现场另算分量。

## 6. CFO（加厚 · 利润入口）

> 粒度=利润入口加权切片；**同链写满**，权重偏向毛利额入口。分量须**已算出呈现**，禁止「自行用 LMDI 拆开看 / 分量待跑数填」类推作业句。

**入口结论：**天津区店日均补贴前毛利额同比 −12%【模拟】，弱于全国大盘 −5pp【模拟】（与区总同入口数）。

**LMDI / 恒等分量（已算【模拟】，直接呈现）：**  
店日均补贴前毛利额变化 ≈ 销售额分量 + 补贴前毛利率分量：  
- 销售额分量约 **−7.2 元/店日**【模拟】；  
- 补贴前毛利率分量约 **−4.8 元/店日**【模拟】；  
两分量同向为负，销售额分量略重于毛利率分量【模拟】。若某期分量字段空缺，写「分量空缺」并保留节点名，**不**改写为叫角色去拆。

**旁证（同月同向，不作故事归因）：**  
- 订购金额 −18% 与时段折扣 ×1.4 同月同向【模拟】——作并行旁证，不写成「因折扣导致订购」故事。  
- 商品旁证一句：猪肉订购 −27%、该品类折扣 ×1.8【模拟】。  
- 消费者旁证一句：来客持平、重量 +6%；老客人均 ¥42·3.1 件高于新客 ¥28·1.8 件【模拟】。

**同链其余段（不删，与区总同构）：**老/新 70%/30%；商品来客最高叶菜 A、最低冰鲜 B【模拟】。

**现在复查：**核对 CFO 利润入口切片表与区经营包——已呈现的销售额分量 / 毛利率分量是否仍约为 −7.2 / −4.8 元/店日且同向；订购与时段折扣同月同向是否仍在表上；品类一句（猪肉订购+折扣）与消费者一句（老客人均）是否仍与区总包一致。**只核对已呈现数，不要求自行重算 LMDI。**
