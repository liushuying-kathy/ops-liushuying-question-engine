## 导读 · 问题定义 → 分解

**定调**：门店是最小经营主体；问题思路自下而上聚合到管理视角；各层经营思路应一致（同一杜邦/MECE 链），差异只在聚合粒度与角色投影。
**定义的问题**：如何在每日/每月扫描中，用可辩护的不等式树，穷尽已成立的经营异常，按 MECE（不双计原因）与**杜邦恒等必拆**下钻，再投影到人？

**本章分解**：发现顺序（入口→定位→过程→投影）→ L1–L4 → 过程树要点 → 80-20 → 三角色主键。  
**过程深度真源**：`10_下钻深度补全_穷尽分析方案.md`（旧「一段只挂一个叶子」浅停读法 → **待废止/待拍板替换**）。证据与触发见 `02` / `05`–`07`；本章保持骨架短文。

## 1. 引擎要做成什么（§1）

每天扫商分库，用不等式找出**已经成立**的经营问题。本阶段不写推送渠道、群、页面跳转。

**真北（§15）**：联通内网数仓 + 每日/每月强逻辑扫描 → 高质量发现商业问题；分发形态后置。

### 发现顺序（固定）

```text
1. 入口：考核净利润摊到店日 → 店日均补贴前毛利额 → 补贴前毛利率（并列判断，短清单只强调一条；码见 `11`）
2. 定位：管理区域 → 运营大区 → 省 → 市 → 店型 → 品类（能汇总的层才发）
3. 过程：**杜邦/恒等层层必拆**（入口→销售额=来客×客单→量价/客件→品类全树→消费者/会员；订购/促销按段挂入）— 详见 `10`；MECE=不把同一异常写成两套原因（**不是**同屏只挂一叶）
4. 投影：按对象主键写入区域单 / 督导单 / 加盟商单 / 店长单
5. 月度两天：L2 写公司重要问题榜（§5.3）与会员槽；日扫永不写 CEO 榜
```

> 落地方案 §4 旧句「一段只挂一个叶子」：样张包内标 **待废止/待拍板替换**；推荐新默认见 `10` §1–§2。

### 三条纪律

1. 每条判断都是不等式或是非；写不出不等式的叶子只标状态，不触发。  
2. 日扫可以出问题，不进公司重要问题榜（§5.3）。  
3. 解法可以空着；没有建议动作不算失败。

## 2. 四层架构（L1–L4 · §15.1 / v4.0 文首）

| 层 | 职责 | 真源产物 |
|---|---|---|
| **L1 发现** | 登记叶子凡有数必检；成立即入库 | `problems.json`（每行 `problem_id`） |
| **L2 提炼** | 全国月频，按 contribution 累加至 80% | `problems_ranked.json`、`ceo_upgrades` / `cfo_upgrades` |
| **L3 呈现** | 问题树 + 下发包 + 对象单 | `problem_trees.json`、`问题清单_*.md` |
| **L4 对象投影** | 同一套叶子不等式与 yaml 阈值；角色差异仅在 `object_key` 可见范围 | 区域经营包 / 督导单 / 店长单等 |

判据在引擎内 L1→L2→L3→L4；Agent 外壳只编排（取数→run_batch→checks→呈现），不改不等式。

## 3. MECE 问题树要点（§4 / §4.1）

旧 T7/T6/T5/T1 **不再**决定「先发现什么」。

**入口（并列）**：考核净利润摊到店日 (E1) · 店日均补贴前毛利额 (E2) · 补贴前毛利率 (E3)。  
**定位**：`manage_area_name` → `sap_area_name` → 省/市 → 店型四格 → 品类（不跨层相加）；运营大区只描述、不进短清单。  
**过程（杜邦必拆 · 见 `10`；中文见 `11`）**：订购（订购金额达标/订购重量）→ 销售（销售金额/销售重量）→ 拆分（来客/客单价及细分）→ 促销 → 消费者（频次/复购/购物篮/客件）；**同屏可展多叶**，用主路径/拆解/并行区分角色。

写不出不等式的叶子只标状态（空缺/待拍板/vacancy 占位），禁止冒充口径（如被动促销轧差、神策首访当新客、频次当复购）；**禁止静默删节点扮浅树**。

恒等示例（§4.1）：E2 LMDI；销售额=来客×客单价；19 点前+后=全天；四格加权之和=已分型店。并行观察关系类型见 `10` §2.2；措辞禁语见 `08` 规则节。

## 4. 80-20（L2 · §6）

```text
店日缺口 = 本期店日均 − 去年同期同口径店日均
贡献 = 子叶子店日缺口 / 父节点店日缺口   （须为金额·元/店日）
```

累加至 `contribution_fold`（默认 **0.80**，与 `ceo_view.fold` 同值）标重点；其余留明细不删。算不出标 `贡献待算`。`category_sale_share` **不是**这套缺口贡献。

## 5. 三角色投影（区域 / 督导 / 店长 · §6）

同一套判据；差异仅在主键可见范围。没有主键的不收单。

| 角色 | 主键 | 单上写什么（摘） |
|---|---|---|
| **区域** | `manage_area_name` | 利润/毛利入口、店型、已成立过程叶；运营大区下钻；省/市挂本区 |
| **督导** | `group_manager_code` | 名下店断在哪一段；无编码店留区域单 |
| **店长** | `sp_store_id` | 本店订购→销售→拆分→促销→消费者，只写成立叶；首屏不放弱提示 |

（加盟商暂用 `contract_franchisee_id`，业务确认「单」指哪套见卡点短表。）
