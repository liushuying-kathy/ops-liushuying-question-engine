# Shaun-coop 协作规则

本文件夹用于协作评论与回复。所有协作默认通过 harness 进行。

## 文件要求

- 只允许 `.md` 或 `.html`。
- 文件名必须为 `yymmdd-xxxxxx`，例如 `260819-需求澄清.md`。
  - `yymmdd`：日期（两位年 + 月 + 日）
  - `xxxxxx`：简短主题

## 回复要求

协作者的回复必须写在既有的 md/html 内，不要为同一条评论另开文件。

- 保留上一版全部原文，不得删改原评论。
- 新回复插在对应原文附近（夹在相关评论之间），不要覆盖或整段重写。
- 每条内容必须标明作者：优先用 GitHub 用户名；若用户向 harness 提供了显示名，则用该名字。
- 作者身份以 harness 侧提供的为准。

## 署名示例

```md
**shaun / AurganicSubstance**
原文评论……

**回复：wangmengxia**
针对上文的回复……
```
