## 愿景

联通内网数仓，按日扫描；用强业务逻辑发现**已经成立**的经营问题（发现质量优先，分发后置）。

- **门店**是最小经营主体；问题自下而上聚合。
- 各角色共用同一条杜邦 / MECE 链：入口 → 定位 → 过程必拆 → 品类 → 消费者；差别只在聚合粒度和投影。
- 用 80-20 定优先级与日 / 月频率。
- 外发行动句统一写「**现在复查**」。

## 完整示范链（天津区 · 取自仓内 samples）

一条链串起来（数字与区名均来自 `engine/runs/samples/` 现稿，不另编）：

1. **扫描 / 触发**：月频榜按全国经营影响排序；样张数据月为 **2026年9月**（见 `问题清单_公司重要问题榜.md` 本页说明）。日路径另有 `问题清单_区域日下发_样张.md`（样张日 2026-09-26，对照=定比去年同星期几）。
2. **下钻（天津区 · 店日均销售额）**：`问题清单_区域经营包.md` 方案对应条款 结论写明——9月店日均销售额同比下降 **14.4%**；恒等拆解见 19点前来客同比下降 **6.1%**；并行观察含进货重量同比下降 **5.1%**。商品分支列蔬菜/水果/猪肉等大分类量价事实；空间下钻见运营大区「天津」销售同比下降 **18.2%**（比天津区弱 3.9 个百分点）。
3. **角色投影**：同一主叶子在公司重要问题榜 / 区域经营包 / 督导单 / 店长单中投影粒度不同——公司榜看全国排序与下发包；区总看区域经营包完整链；督导看公司榜涉及管理区内跟店门店（如店 A1HT（天津区））；店长看订购→销售→促销→会员链路单。
4. **现在复查（措辞）**：外发行动句统一「现在复查」（见根愿景与 `05-措辞与对照/08_问题下发措辞约束.md`）。样张内示例：沿「店日均销售额」核对区域月表与品类加权；基准见正文对照口径。

若需对照字段中文全称，先读 `05-措辞与对照/11_节点中文对照表.md`。【待核】日更调度与加盟主键仍见 `06-样张/03_当前状态与卡点.md`。
